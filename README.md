## Баг-репорты

**BR-01. Вход: тело запроса `null` вызывает ошибку 500.** Серьёзность средняя. Окружение: Windows 11, Node.js 22.14, коммит 0a93b68.
Шаги: отправить POST /api/login с `Content-Type: application/json` и телом `null`.
Ожидали 400 или 401, получили 500, в логе `TypeError: Cannot read properties of null (reading 'login')`. Статус: исправлен в 214f942.

**BR-02. Администратор может завершить заявку на мероприятие, которое ещё не прошло.** Серьёзность средняя, приоритет высокий.
Шаги: войти как admin, для заявки № 5 (мероприятие 27.11.2026) отправить PATCH /api/admin/requests/5/status со `status_id` 2, затем 3.
Ожидали отказ на втором запросе, получили 200 и статус «завершено» 29.10.2026. Статус: исправлен в 214f942.

## Автотест формы входа (задание 4)

Папка `autotests`: Selenium и pytest, шаблон Page Object (`pages/login_page.py`), явные ожидания `WebDriverWait`, скриншот при падении теста (`conftest.py`, папка `failed`).

```
cd autotests

```
